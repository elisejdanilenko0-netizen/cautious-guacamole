# Две неоновые игры

Репозиторий с двумя играми на чистом HTML/CSS/JS + Canvas. Ни сборки, ни зависимостей.

| Файл | Что это | Как запустить |
| --- | --- | --- |
| **`neon-tetra.html`** | неоновый тетрис (hold, очередь, комбо, уровни) | просто открыть файл — он один и полностью самодостаточен |
| **`neon-drift.html`** | неоновый раннер для телефона (собранный в один файл) | просто открыть файл |
| `index.html` | тот же раннер, но в виде ES-модулей | нужен http-сервер (см. ниже) |

Оба single-file варианта работают откуда угодно: с диска по `file://`, из песочницы,
из вложенного iframe — ни одного внешнего запроса, всё внутри одного HTML.

# NEON DRIFT

Неоновый бесконечный раннер для телефона. Ведёшь корабль пальцем, уворачиваешься от стен и мин, собираешь энергию и уходишь в Овердрайв, чтобы ломать препятствия корпусом.

## Запуск

Один файл — просто открыть `neon-drift.html` двойным щелчком.

Модульная версия требует http:// (иначе браузер не даст загрузить ES-модули):

```bash
python3 -m http.server 3000
# открыть http://localhost:3000
```

На телефоне: открой тот же адрес в Wi‑Fi-сети компьютера (`http://<ip-компьютера>:3000`)
или задеплой папку на любой статический хостинг (GitHub Pages, Netlify, Vercel — без настроек).

## Как играть

| Действие | Управление |
| --- | --- |
| Движение | веди пальцем в любом месте экрана (корабль едет за пальцем) |
| Овердрайв | кнопка **ОВЕРДРАЙВ** справа внизу, когда шкала полная (или пробел на клавиатуре) |
| На десктопе | стрелки / `A`–`D`, пробел — Овердрайв, `Enter` — старт |

Правила простые:

- **3 жизни.** Столкновение отнимает одну и даёт 2 секунды неуязвимости (корабль мигает).
- **Энергия** (жёлтые сферы) — очки, комбо и заряд Овердрайва.
- **Бритьё** — пролети вплотную к стене или мине: +15 очков и +1 к комбо.
- **Комбо** растёт, пока подряд собираешь энергию. Пропустил сферу — комбо сгорело. Каждые 5 сфер дают ×0.5 к множителю (до ×5).
- **Овердрайв** — 3.4 секунды неуязвимости, скорость выше, сфера притягивается сама, очки ×2, а стены и мины можно таранить за бонус.
- **Бонусы:** `◈` щит (гасит одно попадание), `⊂` магнит (9 с, притягивает энергию), `◐` замедление (6 с, скорость −38%).

Чем дольше живёшь, тем выше сложность: скорость растёт, проходы в стенах сужаются и начинают ездить из стороны в сторону, мин становится больше.

## Что внутри

```
index.html            разметка + экраны (меню, HUD, конец игры, пауза)
css/style.css         мобильная вёрстка, safe-area, неон
js/main.js            запуск, размеры, ввод, HUD, игровой цикл, пауза
js/game.js            игровое ядро: физика, спавн волн, столкновения, отрисовка
js/fx.js              частицы, всплывающий текст, тряска экрана
js/audio.js           процедурная музыка и звуки на Web Audio (без файлов)
js/util.js            математика и проверка пересечений
tools/make_icons.py   генерация иконок PNG (чистый Python, без зависимостей)
tools/simulate.mjs    прогон игрового ядра в Node с «роботом»: баланс + ошибки
sw.js                 офлайн-кэш (PWA)
manifest.webmanifest  установка на домашний экран
```

### Мелочи, которые приятно

- PWA: добавляется на домашний экран, работает полностью офлайн (service worker + иконки).
- Полноэкранный режим, без зума и скролла, с учётом «челки» (`env(safe-area-inset-*)`).
- Вибрация на Android, адаптивный DPR, пауза при уходе в фон, рекорд в `localStorage`.
- Музыка и звуки синтезируются на лету: размер всей игры — ~100 КБ.
- Игровое поле ограничено колонкой 520 px — на десктопе выглядит как телефон.

## Проверка баланса

```bash
node tools/simulate.mjs
```

Скрипт гоняет ядро в Node с заглушкой canvas и «роботом»: показывает, сколько живёт
средний игрок, от чего умирает (стены/мины) и ловит исключения в логике.

# NEON TETRA

Неоновый тетрис в одном файле (`neon-tetra.html`).

- Классическая механика: 7 фигур, вращение по SRS с отскоками от стенок, «призрак» фигуры.
- **Отложить фигуру** (hold), очередь из 5 (на узком экране — из 3) следующих.
- Очки по гайдлайну: 100 / 300 / 500 / 800 × уровень, бонус за комбо, +2 за клетку резкого сброса.
- Уровень растёт каждые 10 линий, скорость — по формуле `0.8^(уровень-1)` с поправкой.
- Lock delay 0.5 с (до 15 сбросов), DAS 180 мс, повтор 55 мс.
- Управление: стрелки / `Z` `X` / пробел / `C` / `P`; на телефоне — кнопки под полем плюс свайпы
  (влево-вправо — двигать, вниз — мягкий сброс, резко вниз — сброс, вверх — отложить, тап — поворот).
- Раскладка сама перестраивается: на узком экране панели — полосой сверху и строкой снизу,
  на широком — по бокам от стакана.

## Пересборка раннера в один файл

```bash
python3 tools/build-standalone.py   # index.html + css + js -> neon-drift.html
```

Мини-бандлер склеивает ES-модули в один `<script>`, инлайнит стили и подменяет favicon
на data-URI. Если правишь модульную версию — пересобери.

## Тюнинг (NEON DRIFT)

Все «ручки» в одном месте — верх `js/game.js` и геттер `diff`:

- `REF` — ширина, под которую свёрстан мир;
- `this.speed = this.h * (0.44 + 0.40 * diff)` — скорость;
- `get diff()` — как быстро растёт сложность (сейчас максимум через 62 экрана);
- `_spawnWave()` — набор волн и их вес.
